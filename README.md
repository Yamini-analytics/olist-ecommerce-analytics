# Olist E-Commerce Analytics

End-to-end e-commerce analytics project using:

- Snowflake
- dbt
- Git
- GitHub
- Power BI

## Project Objective

Build a real-world e-commerce analytics platform using the Olist Brazilian E-Commerce dataset.

## Technology Stack

- Data Source: Olist E-Commerce Dataset
- Cloud Storage: AWS S3
- Data Warehouse: Snowflake
- Transformation: dbt
- Version Control: Git
- Repository: GitHub
- Visualization: Power BI
